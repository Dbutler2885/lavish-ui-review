# Legacy print-era bases

These files are retired from the live workflow and intentionally reference
imports that no longer exist (print formats, physical sizing).
They are kept as adaptation bases:

- `sandbox-check.mjs` - render-under-Lavish-sandbox checker; becomes the
  mockup renderer in slice 03.
- `intake-server.mjs` + `intake-ui.html` - the local intake web app; becomes
  the visual intent UI in slice 10.

The full print workspace they came from lives in git history (commit
`5b643ca`) and in the sibling `lavish-axi-PDF` repo.
